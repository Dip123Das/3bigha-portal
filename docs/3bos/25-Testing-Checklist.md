# Testing Checklist

## Core Validation

- [ ] TypeScript checking passes.
- [ ] Production build passes.
- [ ] Changed routes load successfully.
- [ ] Existing routes remain available.
- [ ] Database reads and writes behave correctly.
- [ ] Permissions and RLS behave correctly.

## Human Journey

- [ ] The primary task is understandable.
- [ ] Required fields are clear.
- [ ] Entered information is preserved after errors.
- [ ] Success confirmation is meaningful.
- [ ] Recovery from failure is possible.
- [ ] AI-assisted work requires appropriate review.

## Identity and Workspace

- [ ] Correct identities see the feature.
- [ ] Irrelevant identities do not see unnecessary complexity.
- [ ] Workspace navigation remains correct.
- [ ] Multi-identity accounts behave correctly.
- [ ] Legacy accounts remain compatible.

## Growth Plans

- [ ] Start, Grow, Manage and Scale access behaves as intended.
- [ ] Irrelevant capabilities remain hidden.
- [ ] Plan messaging remains encouraging.
- [ ] Limits do not affect identity or dignity.

## Devices

- [ ] Mobile tested.
- [ ] Desktop tested.
- [ ] Important controls remain reachable.
- [ ] Forms remain readable and usable.
- [ ] No unintended horizontal overflow exists.

## Production Readiness

- [ ] Final diff reviewed.
- [ ] Monitoring or health checks identified.
- [ ] Rollback tested or documented.
